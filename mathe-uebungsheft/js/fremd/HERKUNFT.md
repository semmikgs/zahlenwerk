# Fremder Code in diesem Ordner

## qrcode.mjs

QR Code Generator for JavaScript, von Kazuhiko Arase.
Paket `qrcode-generator`, Fassung 2.0.4, unverändert übernommen.

- Quelle: https://www.npmjs.com/package/qrcode-generator
- Lizenz: MIT (steht im Kopf der Datei)

Liegt hier im Repository statt auf einem fremden Server, damit beim Aufruf
der Seite keine Verbindung nach außen entsteht und die Codeliste auch dann
funktioniert, wenn das Schulnetz Fremdinhalte blockt.
